# 3D Interactive Semi-Submersible Rig Visualization using Python
This repository hosts a proof-of-concept, interactive 3D Semi-Submersible Rig plot visualized with Plotly from an OBJ+MTL file converted to PLY. It is optimized specifically for web-based viewing, allowing you to rotate and inspect the model's complex geometry directly in your browser.
