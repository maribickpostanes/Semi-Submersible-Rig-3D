# 3D Interactive Semi-Submersible Rig Visualization using Python
This repository hosts a proof-of-concept, interactive 3D Semi-Submersible Rig plot visualized with Plotly from an OBJ+MTL file converted to PLY. It is optimized specifically for web-based viewing, allowing you to rotate and inspect the model's complex geometry directly in your browser.

Github Pages Link: https://maribickpostanes.github.io/Semi-Submersible-Rig-3D/

## Technical Attribution & Asset Pipeline:
- 3D Model: Oil Rig Platform 3D by RigModels website
- Data Pipeline: Handled natively via a custom Python script. The source OBJ geometry and accompanying material data (.mtl) were compiled, processed, and converted into a single, web-optimized PLY file.
